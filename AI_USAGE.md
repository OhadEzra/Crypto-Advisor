# AI Usage Summary

AI tools were used as a development assistant during the assignment.

## Tools Used

- ChatGPT
- Optional: Cursor / GitHub Copilot, if used during final implementation

## How AI Was Used

AI assistance was used for:

- Understanding the coding-task requirements
- Planning the project architecture
- Designing the backend/frontend folder structure
- Generating initial boilerplate code
- Thinking through authentication and onboarding flow
- Suggesting clean UX patterns for the dashboard
- Creating fallback behavior for external API failures
- Drafting README documentation
- Drafting a future feedback/training process proposal

## Human Work / Final Responsibility

The final implementation, testing, debugging, deployment configuration, and code review are my responsibility. AI output was reviewed, edited, and adapted to match the project requirements.

## Important Design Decision

The app stores thumbs up/down feedback in the database instead of only showing it in the UI. This keeps the project aligned with the requirement that user feedback can support future recommendation improvements.
